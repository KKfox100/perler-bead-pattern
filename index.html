1选择图片

支持 JPG / PNG / WEBP / GIF，也可以直接拖拽或粘贴（Ctrl+V）。图片只在本机浏览器处理，不会上传到任何服务器。

🖼️
点击选择图片，或拖拽到此处
建议选择主体清晰、背景干净的照片，排豆效果最好

2裁剪 建议

拖动裁剪框选择要保留的区域，拖四角可以改大小。裁成成品比例后，排豆既不会四周留白，也不会被二次裁切。 原图始终保留着，随时可以重裁。

3图片优化 可选

先优化再排豆，效果通常好很多——尤其「去背」和「卡通化」，能直接去掉大片杂色豆。 不选任何方案就是直出，直接进入下一步。
选方案、拖参数都会实时预览，下方的图纸同步跟着变，看到满意为止。

⚠️ 关于浏览器直连第三方 AI 接口
· remove.bg、Replicate 等明确不支持 CORS，从网页直接调用会被浏览器拦截。要用它们必须自建代理，或在「CORS 代理前缀」里填入你的转发地址。
· API Key 只保存在本机 localStorage，不会上传到任何服务器；但前端持有密钥本身有泄露风险，请勿在公用电脑上填写。
· 如果接口要求密钥不能出现在前端，正确做法是部署一个后端转发——那样 Key 留在服务端，页面只调你自己的接口，此时把接口地址填成本站后端即可。
